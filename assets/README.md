# Instagram media assets

Upload publishable Instagram images here as JPEG files. Meta's Instagram publishing API supports JPEG for image publishing.

For the first carousel, keep these exact filenames:

- `first-post.jpg`
- `carousel-2.jpg`
- `carousel-3.jpg`
- `carousel-4.jpg`
- `carousel-5.jpg`
- `carousel-6.jpg`

Do not commit access tokens or credentials to this folder or anywhere else in the repository.
